## Selected tools

### 01 — [Apple Music Local Plugin](https://github.com/mikotokuroko/apple-music-local-plugin)

Windows-only local control for Apple Music through `applemusic-mcp`: personal library and playlist workflows stay on the computer, without a tunnel or OpenAI API billing.

### 02 — [Friend Maker](https://github.com/mikotokuroko/friendmaker)

A macOS/Windows toolkit that turns images into pixel grids and ESP32 controller scripts for automatic drawing workflows in *Tomodachi Life* and related projects.

### 03 — [BMTI](https://github.com/mikotokuroko/BMTI)

A playful personality test made for friends—an experiment in giving a lightweight social tool a clear, human-scale purpose.

- I think small, specific details are where software becomes worth returning to.
